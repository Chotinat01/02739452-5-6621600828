# ข้อความแก้แหล่งข้อมูลที่จอง

ผู้ใช้เลือกเปลี่ยนแหล่งที่สามจาก Spoonacular เป็น Forkify เพราะไม่ต้องใช้ API key ให้แก้โพสต์จองเดิมหรือแจ้งอาจารย์ตามกติกาของรายวิชา ผู้ใช้เป็นผู้ส่งข้อความเอง

```text
#จอง 6621600828 โชติณัช โสภาแปง หมู่ [ใส่หมู่]
หมวด: อาหารและสูตรอาหาร
ขอบเขต: รวบรวมสูตรอาหารนานาชาติและวิเคราะห์วัตถุดิบที่ใช้ จำแนกตามประเภทอาหาร พร้อมระบบค้นหาสูตรจากวัตถุดิบ
แหล่ง:
1) TheMealDB — https://www.themealdb.com/
2) Wikibooks Cookbook — https://en.wikibooks.org/wiki/Cookbook:Recipes
3) Forkify API — https://forkify-api.jonas.io/

แก้แหล่งที่ 3 จาก Spoonacular เป็น Forkify API เนื่องจากอ่านสูตรและวัตถุดิบด้วย GET ได้โดยไม่ต้องใช้ API key ขอบเขตหัวข้อเดิม
```

Forkify เป็น API เพื่อการศึกษาซึ่งรวบรวมสูตรจากเว็บอื่น ไม่ใช่เว็บไซต์สูตรต้นฉบับของทุกสูตร โค้ดเก็บ URL endpoint ที่ดึงจริงเป็น provenance โดยไม่เก็บชื่อ publisher หรือข้อมูลผู้ใช้ เวลาปรุงเป็นค่าที่ API รายงาน ไม่ได้วัดหรือยืนยันจากการปรุงจริง
